# Maps

The **Maps** tile of DAME HUB: knowledge, piping and wiring maps.
Served at `/maps/`; opens inside the DAME app after sign-in. Login, users, rights and theme come from the core at `/dame-hub/core/v1/`.

Public repository, code only: no internal data, keys or real files. Data lives in Supabase, schema `maps`, reached through `public.maps_*` functions.

Rule book: `docs/SECURITY.md`, `docs/STANDARDS.md`, `docs/TILE-CONTRACT.md` in the admin repo `dame-hub`. This tile: `docs/TILE.md`, `docs/STATUS.md`.
